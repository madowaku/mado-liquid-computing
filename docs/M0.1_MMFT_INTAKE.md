# MLC-M0.1 MMFT Adapter / Physical Droplet Evidence

Upstream: https://github.com/cda-tum/mmft-simulator

## Plan
1. Inspect supported droplet models and simulator interfaces, pin a commit and confirm license/installation requirements.
2. Build an optional adapter under `src/liquid_lab/backends/mmft/`; keep M0.0 dependency-free at runtime.
3. Define geometry, pressure/flow boundary conditions, fluid parameters, droplet initialization, units and solver settings in a versioned fixture.
4. Export timestamped simulated observations and provenance with explicit `backend=mmft-...` and `evidence_level=S1`.
5. Cross-check simple channel splitting/routing against analytic limits or upstream validated reference examples.
6. Demonstrate that output is derived from simulated flow rather than a hard-coded truth table.

## Acceptance criteria
- Runs from a pinned upstream release/commit and documented environment
- Reproducible fixture and artifact checksums
- Time traces with units; failure and uncertainty reporting
- No fabricated physics simulation claims from synthetic S0 backend
- Maintains M0.0 public CLI and regression tests
